# ADR-0001 — Stack inicial para Nebulosa Wiki

## Estado

Aceptado

## Contexto

Nebulosa Wiki será una aplicación local-first, portable y visual para manejar una wiki Markdown local en Windows. Está pensada para trabajar con Claude Code como memoria persistente: los archivos `.md` son la fuente de verdad, no una base de datos externa.

Requisitos clave:

- Acceso directo al sistema de archivos local (leer/escribir `.md`)
- Interfaz visual con grafo de conexiones entre notas
- Búsqueda local sin servicios externos
- Distribución portable (sin instalador si es posible)
- Ecosistema JS/TS para aprovechar librerías de grafos y Markdown

## Decisión

Stack seleccionado para la primera iteración:

| Capa | Tecnología |
|---|---|
| Shell de escritorio | Tauri (Rust + WebView) |
| UI | React + TypeScript |
| Grafo visual | Cytoscape.js |
| Búsqueda local | MiniSearch (diferido a fase 2) |
| Parser Markdown | librería JS (remark / markdown-it, por definir) |
| Configuración | JSON local (sin base de datos) |

## Alternativas evaluadas

| Opción | Motivo de descarte |
|---|---|
| Electron + React + TS | Binario muy pesado (~150 MB), RAM alta |
| Neutralino.js | Ecosistema pequeño, menos soporte a largo plazo |
| Python + PySide / Qt | Cambio de lenguaje, peor integración con libs JS de grafos |
| Flutter desktop | Ecosistema Markdown/grafo más limitado |
| Avalonia | Ecosistema .NET, alejado del stack JS/TS elegido |
| Web app local + Node.js | Requiere terminal abierta; peor UX como app de escritorio |

## Justificación

Tauri + React + TypeScript es la opción más equilibrada porque:

- **Tauri** produce binarios pequeños (~5–10 MB), consume poca RAM y expone APIs seguras de filesystem sin necesitar Node.js en producción.
- **React + TypeScript** permite usar el ecosistema JS completo: Cytoscape.js para grafos, remark/markdown-it para renderizado, MiniSearch para búsqueda offline.
- **Cytoscape.js** es madura, bien documentada y soporta layouts de grafo complejos con rendimiento aceptable para wikis de tamaño mediano.
- La configuración en JSON local evita dependencias de bases de datos y mantiene los datos completamente portables.
- El stack permite que Claude Code lea, escriba y navegue los archivos `.md` directamente como memoria persistente.

## Riesgos

| Riesgo | Mitigación |
|---|---|
| Curva inicial de Rust/Tauri | Limitar el código Rust al mínimo; usar comandos Tauri predefinidos |
| Permisos de filesystem en Windows | Configurar `allowlist` de Tauri explícitamente; no usar permisos amplios |
| Manejo de rutas en `D:\` | Usar APIs de Tauri para rutas; nunca construir rutas con concatenación manual |
| Empaquetado portable | Validar build portable antes de avanzar en features |
| Dependencias innecesarias | Revisar cada dependencia antes de agregarla al proyecto |
| Protección de datos reales | No apuntar a carpetas de producción durante desarrollo; usar carpeta de prueba separada |
